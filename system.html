A design system whose heaviest user is an AI

The AI in Repair AI never draws UI. It returns data, and the app renders it with the components on this page. Engineers and coding agents read the same tokens, components and rules, so the right choice is the default.

Principles

Six decisions the whole system follows

01

The AI never draws UI

It returns data in a fixed shape. The app chooses the component.

02

The cost of being wrong decides

Cheap and sure: act. Unsure or expensive: suggest. Can't tell: ask.

03

The UI enforces the rule

If the model breaks a rule, the component corrects it. Trust can't depend on the prompt.

04

Never a dead end

Every "no" comes with a next step. Every AI decision has a one-tap way out.

05

Red means risk

Red appears only where the user could lose money or time. Never as decoration.

06

The user's work survives

An AI update never undoes a decision the user already made.

Foundations

Tokens

Two tiers. Primitives hold raw values; semantic tokens say what a colour means. Components take colours from semantic tokens only, so a new theme or brand changes token values, never components. Values shown are live for the current theme.

Two token tiers: primitive (tier 1) and semantic (tier 2). The component class at the start and the resolved value at the end are not tiers, so the path has three steps.

AI
For coding agents

  
How a coding agent (like Claude Code) builds a new Repair AI screen from this system without a designer in the room.

  

    

      
1
Read the rules first
RULES.md and tokens.css are the source of truth.

      
2
Use components, not markup
Call the functions in components.js. Never rebuild a card by hand.

      
3
Semantic colours only
No hex values or colour primitives in components.

      
4
Keep the guard
Model output always passes through guard() before rendering.

    

    
Example instruction for the agent
Build the "Order tracking" screen for Repair AI.

Before writing code:
- Read RULES.md and tokens.css.
- Reuse components.js (partCard, chips, quoteRow).
- Colours: semantic tokens only (--s-*). Space, radius, type, motion: primitives (--p-*).
- Red = risk only (rule 8). Every action has an undo (rule 5).
- Copy: plain words for a mechanic (rule 6).

If a pattern you need doesn't exist, stop and
propose a new component with "Use when / Never".
