# Repair guide image prompts

Save each image as `shots/repair/<file>.jpg` (about 1200×900). The guide picks it up automatically; until then the Corolla shows the line drawing and other cars show no image.

Tips: make the first image of each car, then reuse it as the style/character reference for the rest of that car. Check left/right: the car's left is the viewer's right in a front view.
